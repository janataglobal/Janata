Cloudflare Pages upload package for Janata Global Exports

Upload the contents of this folder to Cloudflare Pages as a static site.

Included files:
- index.html
- styles.css
- script.js
- privacy.html
- terms.html
- robots.txt
- sitemap.xml
- favicon.svg
- assets/ (logo and hero illustration)
- functions/enquiry.js

Important:
- For the quote form email delivery to work, add the RESEND_API_KEY environment variable in Cloudflare Pages.
- If you do not add the secret yet, the form will still validate and return a clear message.
